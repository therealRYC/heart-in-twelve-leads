# The Heart in Twelve Leads

An illustrated, interactive guide to electrocardiography: 27 chapters, from one ventricular cell
to artificial intelligence, with every tracing simulated from one 3D heart.

**Open it: https://therealryc.github.io/heart-in-twelve-leads/**

For learning to read ECGs, not for clinical decisions. Every tracing is simulated.

This repository holds only the built site: one self-contained page, `index.html`, which also runs
offline once downloaded, and `og.png`, the picture shown when the link is shared.
